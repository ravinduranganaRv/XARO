# XARO Industries - store preview

Front-end preview of the XARO Industries (Pvt) Ltd store: real-time 3D tufted-rug scene (custom WebGL, no libraries), product 3D viewer, custom rug builder, cart and checkout rules, order tracker.

**This is a preview. No payment is taken and nothing ships from it. Cart, orders and waitlist live only in the visitor's browser.**

- `index.html` - the built, standalone page (served by GitHub Pages)
- `src/store.src.html` - editable source; `src/img.json` base64 images; `src/catalog_public.json` products and prices
- `build.py` - `python3 build.py` regenerates `index.html` from `src/`
